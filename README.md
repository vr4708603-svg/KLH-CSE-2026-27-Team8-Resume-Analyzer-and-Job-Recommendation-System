## Abstract

This project analyzes resumes using artificial intelligence, extracts relevant skills and experience, and recommends suitable job opportunities. The system aims to improve matching accuracy and help users understand which skills to develop for target roles.

## Repository Structure

- `src/` - Application source code
- `docs/` - Project documentation
- `data/` - Local datasets or references to external data sources
- `results/` - Experimental and evaluation outputs
- `reports/` - Review and final reports

## Setup

1. Install Python 3.10 or later.
2. Create and activate a virtual environment.
3. Install dependencies when added to `src/requirements.txt`.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r src/requirements.txt
```
